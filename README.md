# Excel Data Processor

Набор Python-скриптов для автоматизированной обработки Excel-файлов и преобразования исходных данных в CSV.

## О проекте

Проект предназначен длля упрощения подготовки табличных данных к дальнейшему анализу и загрузке в БД.

Скрипты выполняют обработку исходных Excel-файлов, преобразуют данные и формируют CSV-файлы для последующего использования.

## Основные возможности 

- Чтение Excel файлов.
- Обработка и преобразование табличных данных.
- Подготовка данных для дальнешего использования
- Экспорт обработанных данных в CSV.

## Технологии

- Python
- Pandas
- Tkinter
